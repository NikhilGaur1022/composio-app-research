What the 100 apps say

  1. Auth is a solved problem. 71 of 100 apps expose OAuth2, 70 expose an API key, and 48 expose both. Only 2 have no auth at all (they are CLIs). Nothing in the set needs an exotic auth adapter.
  2. 72% of apps are self-serve (57 free tier, 15 trial). Dev/Infra is 10/10 self-serve, CRM and Comms 9/10. The gated categories are AI/Media (6/10 gated), Marketing/Ads (5/10), Data/SEO (5/10) and Finance (4/10).
  3. The blocker is commercial, not technical. 36 apps have a blocker; 15 are 'paid tier only', 6 are app review, 5 enterprise-only, 5 partner/contact-sales. Only 1 app was undocumented and only 2 lack an API entirely.
  4. Official MCP servers are now the norm: 59 of 100 vendors ship one. Four of those (Plain, Pumble, systeme.io, Amazon SP-API) were so new my own hand labels said 'none' - the agent's evidence overturned them.
  5. 64 green / 28 yellow / 8 red. 16 green apps are not yet in Composio's catalog (Twilio, Front, Zoho Cliq, Lark, Vonage, WooCommerce, BigCommerce, MongoDB Atlas, ...) - those are the immediate wins. The 8 reds split into 5 that need a sales/partner conversation (PitchBook, Ramp, Brex, Waterfall, Salesforce Commerce Cloud) and 3 that are not APIs at all.

The agent

A Python pipeline. Deterministic lookups run first and cost nothing; the LLM only fills gaps and is never trusted without a quote. Claude Code headless (claude -p, structured JSON output, WebSearch + WebFetch) is the research runtime; Composio's toolkit catalog is the first registry consulted. Every stage writes one JSON file per app, so any run is resumable and any row is auditable.

1 · registriesComposio catalog, APIs.guru, MCP registry, GitHubComposio hit 67/100 · OpenAPI spec 25/100 · MCP registry 74/100
2 · probesHit the API unauthenticated70 APIs answered 4xx · 18 sent WWW-Authenticate · 21 OIDC discovery docs · 4 hidden OpenAPI specs
3 · pass 1Haiku, search snippets onlyweak baseline · 0 failures · ~$0.12/app
4 · pass 2Sonnet, fetch docs, verbatim quotesregistry + probe context injected · 0 failures · ~$0.35/app
5 · judgeQuote grounding, no LLM710 quotes checked · 472 found verbatim (66%) · 9 pages unreachable
6 · mergeWeighted vote per field → confidencerule-based verdict · family consistency checks · human queue of 18
7 · humanBrowser checks on the queue10 apps touched · 16 fields corrected · 5 browser checks

Where a human was needed

  • Rebrands and moved docs. fanbasis.com now 301s to commas.com; the agent saw an 'Enterprise & APIs' marketing page and called it partner-gated. The real API reference is at commasdocs.com with self-serve scoped keys. Coda's docs moved to docs.superhuman.com and Binance's to developers.binance.com - the agent handled both of those on its own.
  • Bot-blocked sites. pitchbook.com returns 403 to anything that is not a browser. The agent still found the public OpenAPI spec at api.pitchbook.com/api-docs (130 operations), but only a real Chrome session could read the help page that says API access 'requires a standalone contract agreement'.
  • Pricing tables are JavaScript. The 'access' field lives on pricing/signup pages, and those are mostly JS-rendered comparison grids that WebFetch flattens. Attio (API on Free), Devin (API from Pro only) and iPayX (5 free audits, API on paid) were all resolved by opening the page in Chrome and reading the tick marks.
  • Quote grounding fails on JS docs. Mintlify/ReadMe-style docs (Intercom, Clay, Coda, SE Ranking, Datadog, MongoDB) return near-empty HTML to a plain fetch, so correct quotes could not be grounded and confidence dropped. 12 of the 18 queued apps were queued for this reason and turned out to be right on every field checked.
  • Ambiguous identity. 'Paygent Connect' matches a Japanese payment gateway, an unrelated crypto wallet and an NMI reseller brand; no primary doc could be found. Left as partner-gated with low confidence. 'Consensus' has an MCP in the official registry - but it belongs to goconsensus.com (sales demos), not consensus.app; the agent caught that itself.
  • CLIs are not APIs. Sherlock and Mermaid CLI have no hosted API. They are buildable as local agent skills, not as Composio toolkits; the verdict rule marks them red with blocker 'CLI, not an API' and breadth was reset to unknown by hand.

What went wrong, honestly

  • Pass 2 called Attio 'paid plan'. It quoted 'API and webhook access' from the pricing page but did not see which columns had the tick. Fixed by browser check.
  • Pass 2 called Slack's MCP 'community' although Slack's official mcp.slack.com went GA in February 2026 (pass 1, with less context, had it right). Registry and GitHub hits for community servers outweighed the vendor changelog. Fixed by hand.
  • The first merge made MCP worse than pass 2 alone (71% vs 54% on the gold set): registries index community servers but lag vendor-hosted remote MCPs, so registry 'community' votes outvoted grounded vendor evidence. Fixed by treating 'official' as an existence claim that registry silence cannot refute, and by adding a live probe that POSTs an MCP initialize to the claimed endpoint (mcp.systeme.io/mcp answers 405/401 - it exists).
  • My own gold labels were wrong 4 times (all on MCP: Plain, Pumble, systeme.io, Amazon SP-API). The agent's grounded quotes and the endpoint probe caught them; the labels were corrected only after re-reading the primary source. They are listed in gold.json under _gold_corrections.
  • The judge cannot ground quotes on JavaScript-rendered docs, which produced false low-confidence flags for 12 apps. A headless-browser fetch in the judge would fix this; it was out of budget.
  • Composio SDK could not be exercised live: the provided key returned 401 on every call. The catalog data came from Composio's public toolkit index instead (same fields). Independently of that catalog, pass 2 agreed with Composio's declared auth on 60/67 overlapping toolkits; the 7 differences are all Composio '_mcp' wrapper toolkits whose auth is 'Composio link', not the vendor API's auth.
  • 'Final' accuracy on the gold set is 100% by construction - the corrections were found through the same review. The honest generalization estimate is the merged 95% (before any human touch), and the pass 1 to pass 2 jump (85% to 97%) is the value of fetching primary docs and demanding verbatim quotes.
  • Paygent Connect defeated the agent and me. No primary documentation for a product with that exact name could be found.

Run it

Source: github.com/NikhilGaur1022/composio-app-research. Needs Python 3.11+ and either a logged-in Claude Code CLI or ANTHROPIC_API_KEY. A Composio key is optional (falls back to the public catalog).

pip install -r requirements.txt
python -m agent.run all --app "Attio"        # one app, every stage
python -m agent.run all                       # all 100, resumable
python -m verification.scoring                # score against gold
python -m page.build                          # rebuild this page

Runnable trigger: the repo's Research one app GitHub Action (workflow_dispatch) runs the full pipeline for any app name and commits the JSON. Add a new app by appending to apps.json.
